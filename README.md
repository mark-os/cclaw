# CClaw

A lightweight AI agent written in C. Minimal feature set: Telegram bot → agent loop → OpenAI-compatible LLM endpoints.

Inspired by [Pi](https://github.com/earendil-works/pi) and [OpenClaw](https://github.com/openclaw/openclaw).

## Project Structure

```
cclaw/
├── src/          # C source files
├── include/      # C headers
├── test/         # Tests
├── docs/         # Design docs, reference maps
├── vendor/       # Cloned C libs (gitignored)
├── reference/    # Pi & OpenClaw clones for study (gitignored)
└── build/        # Build output (gitignored)
```
